# Карьер NETA: цифровой двойник на OpenEgiz

Командный репозиторий [team-011](https://github.com/openegiz-contest/team-011) конкурса «Цифровой рудник на OpenEgiz».

Живой стенд — открытый медный карьер с тремя модулями (диспетчеризация, негабарит, допуск после взрыва), режимами А/Б и сценариями «что если». Описание: [SUBMISSION.md](SUBMISSION.md). Презентация: [presentation.pdf](presentation.pdf).

## Запуск

Окружение судьи уже содержит Docker; пользователь в группе `docker`. Нужен только `make`. Выполнять из **корня этого репозитория**:

```bash
sudo apt install -y make
make pit
```

`make pit` поднимает платформу OpenEgiz и карьер NETA (двойники, симулятор, сервисы модулей, UI). Первый запуск обычно несколько минут (образы и сборка), лимит окружения судьи — 75 минут.

**Критерий успеха:** команда печатает `OK: stand ready`, открывается http://127.0.0.1:8095/, в шапке карты зелёный индикатор «поток Ditto SSE».

Остановка: `make down`. Полная очистка данных и паролей: `make clean`.

Пакетный замер А/Б модулей (после успешного `make pit`, образ `neta/pit:local` уже собран):

```bash
make pit-experiment SHIFTS=30
```

Подробности платформы: [OPENEGIZ.md](OPENEGIZ.md) / [OPENEGIZ.ru.md](OPENEGIZ.ru.md).

## Что открыть

После `make pit` скрипт печати адресов выведет URL и логины. По умолчанию:

| Что | Адрес |
|---|---|
| **Карта карьера (главная визуализация, 2D; есть и 3D), режимы А/Б, сценарии** | http://127.0.0.1:8095/ |
| Eclipse Ditto (двойники `neta.pit:*`) | http://127.0.0.1:8080/ |
| Grafana → дашборд «Карьер NETA — модули 1–3» | http://127.0.0.1:3000/ (логин/пароль в выводе `make pit` и в `deploy/compose/.env`) |

### Как увидеть эффект за несколько минут

1. Открыть http://127.0.0.1:8095/ — **2D-карта** с движением техники из Ditto (главная визуализация).
2. Вкладка **«Управление»** → режимы 1–3: **А** = без модуля, **Б** = модуль включён.
3. Нажать **«Перезапустить смену»** после смены режима — тот же seed, честное сравнение А vs Б.
4. Сценарии «что если» — тумблеры ниже на той же вкладке; **«Отменить все»** снимает их.
5. Вкладка **«Показатели»** — тоннаж, диспетчер, дробилка, взрыв. Grafana — газы и простои.
6. Числа по 30 сменам: `make pit-experiment SHIFTS=30` (после `make pit`).
